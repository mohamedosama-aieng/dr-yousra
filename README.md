# Dokkan Decor — Landing Page

كورس الطباعة على القماش من البيت — صفحة هبوط احترافية باللغة العربية.

## الوصف

صفحة هبوط (Landing Page) كاملة باللغة العربية واتجاه RTL لتسويق كورس تعليم الطباعة على القماش من المنزل. الصفحة مبنية بتقنيات HTML/CSS/JavaScript خالصة بدون أي مكتبات خارجية.

## المحتويات

- **هيرو** — عنوان رئيسي مع فيديو VSL من يوتيوب
- **السعر** — كارد تسعير مع عداد تنازلي وبروجرس بار
- **آراء المتدربات** — 3 كاردات بشهادات حقيقية
- **رحلة المدربة** — تايملاين من 2020 لـ 2025
- **قصص النجاح** — 6 فيديوهات يوتيوب شورتس
- **محتوى الكورس** — 5 محاور أكورديون
  - المحور الأول: خامات وأدوات الطباعة
  - المحور الثاني: طباعة التيشرتات والشنط (عملي)
  - المحور الثالث: استخدام الذكاء الاصطناعي (تقني)
  - المحور الرابع: صباغة الأقمشة
  - المحور الخامس: تسعير الشنط والتيشرتات
- **الهدايا** — 3 هدايا مجانية بقيمة $30
- **الباقة الشاملة** — كل المحتويات والهدايا
- **ضمان استرجاع المال** — 7 أيام
- **الأسئلة الشائعة** — FAQ أكورديون

## التقنيات

- HTML5 + CSS3 + Vanilla JavaScript
- خط Cairo من Google Fonts
- تصميم RTL كامل
- Dark theme مع لمسات خضراء `#00e676`
- Responsive تصميم متجاوب (موبايل + تابلت + ديسكتوب)
- يوتيوب بلاير مدمج (YouTube Embed)
